About MCP Server Import

The MCP (Migration Control Plane) server connects directly to your APIC controller to fetch live ACI fabric data.

Benefits:

  • Real-time data directly from APIC
  • No manual file exports needed
  • Automatic data transformation
  • Scheduled data refresh capability

Requirements:

  • MCP server deployed and running
  • Network connectivity to MCP server
  • MCP server configured with APIC credentials

Note: See gcp-deployment/README.md for MCP server deployment instructions.
